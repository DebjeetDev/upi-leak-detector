  🎯 ONE-LINE:
     From a list of monthly bills, find the charges that appear
     3 or more times — those are subscription leaks.
     Tell the user: which one, how much, and the count.

----------------------------------------------------------------
STORY (why this matters)
----------------------------------------------------------------
  UPI deducts money SILENTLY. Netflix is going out, Gym is going
  out — and the owner doesn't even know. If the same name+amount
  keeps appearing again and again, it is almost certainly a
  recurring subscription. Small list, big pain. That's why this
  project is called: LEAK DETECTOR.

----------------------------------------------------------------

REQUIREMENTS (rules without code-links)
----------------------------------------------------------------
  R1  Function name: findLeaks(bills) => [DONE]
  R2  Input check: is it actually a list? No → house 400 envelope.=> [DONE]
  R3  Garbage rows inside (missing month/name/amount, or amount
      not a number): skip QUIETLY — never crash. => [DONE]
  R4  ONE name + ONE amount | the pair appearing 3 or more times
      (months may differ — do NOT join on month)
      = LEAK.
  R5  Anything seen only TWICE: leave it — no suspicion yet
      (this module's line: 2 < threshold <= 3).

        Spotify only 2.
  R6  Every leak is reported exactly ONCE. Order = the order
      each pair was first seen.
  R7  Return envelope (house style, same everywhere):
      success → { status:200, ok:true, data:[...], leaksCount }
      fail    → { status:400, ok:false, error:"..." }
